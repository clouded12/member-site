# member-site

## 概要
このプロジェクトは登録したユーザーのみがログインでき、ログイン後にTodoリストを操作できる機能のある会員サイトを構成するものです。

## 使用技術
# フロントエンドフレームワーク
Next.js/React/TailwindCSS
# フロントエンド言語
TypeScript
# バックエンド
Node.js/Prisma/JWT/Redis
# データベース
PostgreSQL
# インフラ
Docker
# ログイン認証
Redis + JWT


## 使い方
# 前提条件
- Docker Desktopをインストールしてあり、起動していること。
1. PowerShell または コマンドプロンプトで、docker compose up -d を実行する。
2. コンテナ起動後、ブラウザで localhost:3000 にアクセス、 ログイン画面に遷移する

## 機能
- メールアドレス、ユーザー名、パスワードの入力で、新規会員登録
- パスワードを忘れた場合、メールアドレスと新しいパスワードを入力してパスワード再設定(メールを送信して再設定する機能はありません)
- 登録してあるメールアドレスとパスワードを入力でログイン
- ログイン後、プロフィール画面から現在のユーザー名と、メールアドレスを確認
- ユーザー名、メールアドレス、パスワードを変更可(パスワードの変更後は再ログインが必要)
- ログインしているユーザーのデータを削除
- ログイン後、Todoリストが操作可能(タスクの追加、タスクの完了状態切り替え、タスクの削除)
- ログアウトして、ログイン画面へ戻る
